# EC-6-2 Web Flasher

Browser-based USB firmware installer for the Easy Controller 6-2 (EC-6-2) by QRO.CZ.

**Flash it here: https://ok2zaw.github.io/EC-6-2/**

## How to use

1. Open the link above in **Chrome** or **Microsoft Edge** on desktop (Safari and Firefox do not support Web Serial and cannot be used).
2. Connect the device to your computer via USB.
3. Click **Install Firmware** and select the correct serial port when prompted.
4. Wait for flashing to finish without disconnecting the USB cable.

Flashing runs over USB serial at 115200 baud.

## About this repo

This repo only hosts the compiled firmware and the flasher page. It is published automatically from the private source repository whenever a new build is pushed — files here are generated and should not be edited by hand.
