SixByTwo Firmware Installer

Requires a browser with Web Serial support: Chrome or Microsoft Edge on desktop. Safari and Firefox are not supported.
  1. Connect the device to this computer via USB.
  2. Click the button below and pick the correct serial port when prompted.
  3. Wait for the flashing progress to finish — do not disconnect the USB cable.
Your browser does not support Web Serial. Please use Chrome or Edge on desktop. Web Serial is only available over HTTPS (or localhost).

Firmware flashes over USB serial at 115200 baud.
